# Terminal Basics

The terminal is a command-line interface used to interact with Linux.

## Basic Commands

### Print a message

```bash
echo "Hello Linux"
```

### Show current user

```bash
whoami
```

### Show current directory

```bash
pwd
```

### List files

```bash
ls
```

### List detailed information

```bash
ls -l
```

### Show hidden files

```bash
ls -a
```

### Clear terminal

```bash
clear
```

### Show command history

```bash
history
```

### Exit terminal

```bash
exit
```

## Useful Shortcuts

| Shortcut | Use |
|---|---|
| `Tab` | Auto-complete |
| `↑` | Previous command |
| `Ctrl + C` | Stop running command |
| `Ctrl + L` | Clear terminal |
| `Ctrl + D` | Exit |
