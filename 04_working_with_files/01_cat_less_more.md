# cat, less, and more

These commands are used to **view the contents of files**.

## `cat`

Displays the entire file at once.

```bash
cat file.txt
```

Display multiple files:

```bash
cat file1.txt file2.txt
```

---

## `less`

Views a file **page by page**.

```bash
less file.txt
```

Useful for large files.

Press:

```text
Space → Next page
b     → Previous page
q     → Quit
```

---

## `more`

Also displays a file page by page.

```bash
more file.txt
```

`less` is generally more powerful and commonly preferred.

---

## Quick Reference

| Command | Purpose |
|---|---|
| `cat` | Display entire file |
| `less` | View file page by page |
| `more` | View file page by page |
